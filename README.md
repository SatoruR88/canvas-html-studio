# Canvas HTML Studio

端末内のHTML・CSS・Markdownを、紙面を操作するように編集する一人用のWindowsアプリです。

## 主な使い方

1. 「フォルダーを開く」でWebサイトのフォルダーを選びます。
2. キャンバス上の要素を選び、右側の設定で文字・余白・配置・画像などを調整します。
3. 「チェック」で参照切れを確認します。
4. Windows版では `Ctrl+S` で元のフォルダーへ保存できます。Web版ではZIPを書き出します。

Markdownを読み込むと、文書向けのHTMLへ自動変換できます。元のMarkdownは素材として残ります。

## データの扱い

- サイト、編集内容、設定、バックアップは端末内で処理します。
- 共有、共同編集、アカウント連携はありません。
- フォルダーへ上書き保存する前に、`.canvas-html-studio/backups` へ復元用コピーを作成します。
- ZIPやフォルダーの読み込み時は、安全でないパス、重複、過大なファイルを拒否します。

詳しい方針は `PRIVACY.md` を参照してください。

## 開発用コマンド

- `npm run dev`: Windowsアプリを開発モードで起動
- `npm run build`: NSISインストーラーを生成

インストーラー生成は、バージョン番号・権利者表記・リリース内容が確定した最後の工程で行います。
